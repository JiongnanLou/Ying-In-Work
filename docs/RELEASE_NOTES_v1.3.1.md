# 萤 In Work v1.3.1

本版本删除正常速度主动寻人，仅保留 Link 2 原生人像追踪。

- 未见人像时等待，不再由软件发送主动扫视指令。
- 保留原生追踪开关、前台活动暂停与恢复，以及本机摄像头兼容。
- 设置和状态文案更新为“原生人像追踪”。
- 保留工位视窗、Qwen 状态观察、提醒、专注计时、摄像头猜拳与桌面悬浮窗。

38 项自动回归测试及桌面启动检查通过。原生追踪实际转动与持续居中效果仍待实机验收，本版本不宣称解决此前的硬件追踪异常。

直接使用请下载 `YingInWork-v1.3.1-windows-x64.zip`，解压后运行 `萤InWork.exe`。源码开发请另外下载 `runtime-windows-x64.zip`，按 README 准备组件。两者均不包含个人密钥、偏好或数据库。
